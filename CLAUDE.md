## Project Overview

Research codebase for an FX risk policy paper analyzing currency mismatch risk in African infrastructure finance. The core question: how to price an emergency liquidity insurance instrument that absorbs real exchange rate risk for projects with local-currency revenues and hard-currency (USD) debt obligations.

## Setup and Running

```bash
# Create virtual environment and install dependencies
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
.venv\Scripts\activate         # Windows
pip install -r requirements.txt

# Run the main analysis notebook
jupyter notebook notebooks/consolidated_currency_analysis.ipynb
```

## Architecture

### Data Pipeline

1. **Raw data extraction**: `source/extract_Erates_and_Pindex_from_MFMOD.py` extracts exchange rate (PANUSATLS) and price index (NECONPRVTXN) series from a gzipped MFMOD model file (`.wf2` format) into CSV
2. **Core analysis functions**: `source/data_analysis_functions.py` is loaded by notebooks and provides all shared computation logic
3. **Notebooks**: Jupyter notebooks in `notebooks/` consume functions from `source/` and data from `data/`

### Key Data Concepts

- **Hybrid index H = P/X**: Domestic price level divided by nominal exchange rate (USD/LCU). Measures USD value of local goods basket. A decline means real depreciation.
- **Baseline**: 5-year backward-looking moving average of H
- **Events**: Periods where H falls >10% below its MA baseline, ending when it returns within 10%
- Column naming convention in raw data: `{ISO3}PANUSATLS` (exchange rate), `{ISO3}NECONPRVTXN` (price index) where ISO3 is a 3-letter country code

### Core Functions in `source/data_analysis_functions.py`

- `build_hybrid_index_and_ma_df()` — Constructs the hybrid index and moving average baseline from raw data. Returns tidy DataFrame with columns: country, year, fx_index, baseline, nominal_fx
- `compute_terminal_residuals()` — Calculates PV of net normalized deviations over fixed-horizon windows (rolling or non-overlapping). Uses `fx_index` column from the hybrid index DataFrame
- `identify_events()` — Detects devaluation episodes using peak detection (scipy argrelextrema). Returns both event-level summary and augmented country-year DataFrame with in_event/annual_loss columns. **Mutates the input DataFrame** by adding `in_event` and `annual_loss` columns
- `calculate_simple_risk_premium()` / `calculate_event_based_risk_premium()` — Two approaches to actuarial pricing from event data

### Notebook Roles

| Notebook | Purpose |
|---|---|
| `consolidated_currency_analysis.ipynb` | **Main notebook** — full analysis pipeline, motivation, model, results |
| `events_From_baseline.ipynb` | Event detection from MA baseline, actuarial pricing, 20-year rolling integrals |
| `new_event_analysis.ipynb` | Annual prevalence approach, Bayesian modeling (PyMC), Monte Carlo portfolio simulation |
| `SolvencyAnalysis.ipynb` / `SolvencyInverse.ipynb` | Earlier/alternative terminal liability calculations |
| `events_From_trough.ipynb` | Alternative event detection measuring from trough, choropleth maps |

### Key Dependencies

- **pandas/numpy**: Data manipulation and numerical computation
- **altair**: Primary visualization library (not matplotlib, which is also installed)
- **scipy**: Signal processing for peak/trough detection in event identification
- **pymc/pytensor/arviz**: Bayesian modeling in `new_event_analysis.ipynb`
- **geopandas/shapely**: Geographic visualization (choropleth maps)
